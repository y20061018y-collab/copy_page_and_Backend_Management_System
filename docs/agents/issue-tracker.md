# Issue Tracker

This repository uses a local Markdown issue tracker.

## Location

Issues live under `.scratch/<feature>/issues/`. The current feature directory is `.scratch/11hao-esports/issues/`.

## Workflow

- Create one Markdown file per issue.
- Include the issue title, problem, scope, acceptance criteria, blockers, and status.
- Use `ready-for-agent` when an issue is self-contained and ready for implementation.
- Keep blocking edges explicit in the issue file.
- Do not treat generated tickets as raw incoming issues requiring triage.
