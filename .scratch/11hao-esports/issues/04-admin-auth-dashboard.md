# 04 — 建立管理员登录和后台概览

**What to build:** 让管理员可以安全登录后台，并在概览页看到当前游戏和服务数据状态。

**Blocked by:** 02 — 建立游戏数据基础与前台游戏卡片

**Status:** ready-for-agent

- [ ] 建立管理员账号模型、密码哈希和管理员初始化命令
- [ ] 提供登录、退出和当前管理员接口
- [ ] 使用 JWT HttpOnly Cookie 保存登录状态，生产环境支持 Secure 和 SameSite 配置
- [ ] 未登录访问后台写接口返回 401
- [ ] 登录失败使用统一错误信息，不泄露账号是否存在
- [ ] 提供 `/admin/login` 登录页，登录成功跳转 `/admin`
- [ ] 未登录访问后台页面时跳转登录页
- [ ] 提供 `/admin` 概览页
- [ ] 显示游戏总数、启用游戏数、服务总数、启用服务数和最近更新时间
- [ ] 后台桌面端使用导航布局，移动端使用可操作的抽屉导航
- [ ] API 测试覆盖密码认证、Cookie、退出、未认证拒绝和概览统计
- [ ] 浏览器测试覆盖登录、登出和登录保护
