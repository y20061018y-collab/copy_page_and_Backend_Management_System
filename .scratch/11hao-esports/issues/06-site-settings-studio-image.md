# 06 — 完成网站配置和工作室图片更换

**What to build:** 让管理员可以维护网站基础信息、联系方式和工作室图片，并让访客在前台看到已保存的品牌内容。

**Blocked by:** 04 — 建立管理员登录和后台概览

**Status:** ready-for-agent

- [ ] 提供 `/admin/settings` 网站设置页面
- [ ] 支持编辑网站名称、副标题、微信号、QQ 号、电话和咨询提示文字
- [ ] 支持选择工作室图片并在后台本地预览
- [ ] 支持上传和替换工作室图片，保存后才正式关联新图片
- [ ] 使用 `图片/工作室图标.jpg` 作为默认工作室图片

- [ ] 前台顶部品牌区域和页脚显示当前工作室图片
- [ ] 前台刷新后显示最新网站名称、副标题、联系方式和工作室图片
- [ ] API 测试覆盖设置读取、保存、图片校验和替换
