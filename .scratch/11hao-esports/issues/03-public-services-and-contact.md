# 03 — 完成前台服务价格弹窗和联系方式

**What to build:** 让访客可以查看每个游戏的服务价格和说明，并通过咨询入口查看和复制工作室联系方式。

**Blocked by:** 02 — 建立游戏数据基础与前台游戏卡片

**Status:** ready-for-agent

- [ ] 点击游戏卡片打开服务价格弹窗
- [ ] 桌面端显示居中弹窗，手机端显示接近全屏且可滚动的弹窗
- [ ] 价格弹窗只显示当前启用服务，并按排序值升序展示名称、价格和说明
- [ ] 支持关闭按钮、点击遮罩关闭和 Escape 关闭
- [ ] 提供公开网站配置接口，只返回前台需要的配置
- [ ] “立即咨询”按钮打开联系方式弹窗
- [ ] 已配置的微信、QQ 和电话支持复制
- [ ] 移动端电话支持直接拨号
- [ ] 空的联系方式不显示，全部为空时显示管理员配置提示
- [ ] 前台实现响应式交互和 `prefers-reduced-motion` 支持
- [ ] 测试覆盖服务弹窗、禁用服务隐藏、联系方式显示、复制和拨号行为
