# 05 — 完成后台游戏和服务管理

**What to build:** 让管理员可以在后台维护游戏资料、游戏服务、价格、排序、启用状态和游戏封面，并让修改后的内容显示在前台。

**Blocked by:** 04 — 建立管理员登录和后台概览

**Status:** ready-for-agent

- [ ] 提供游戏列表页面，支持全部、启用和禁用筛选
- [ ] 支持新增和编辑游戏名称、slug、标签、简介、主题色、辅助色、排序值和启用状态
- [ ] 支持游戏启用、禁用、恢复和排序，禁用操作需要确认
- [ ] 在游戏编辑页展示并管理该游戏的服务列表
- [ ] 支持新增、编辑、启用、禁用、恢复和排序服务
- [ ] 服务支持名称、价格文本、说明、排序值和启用状态
- [ ] 游戏和服务分别保存，不使用一个整页聚合保存请求
- [ ] 表单显示未保存状态，离开页面前提示未保存修改
- [ ] 支持游戏封面本地预览、上传、替换和保存后关联
- [ ] 仅接受 JPG、JPEG、PNG、WEBP，单文件最大 5MB，并校验 MIME 类型
- [ ] 服务端生成安全文件名并持久化上传文件，替换成功后清理旧封面
- [ ] 管理后台在手机端将列表转换为卡片布局
- [ ] 前台刷新后只显示最新启用游戏和服务
- [ ] API 测试覆盖 CRUD、排序、状态、冲突、校验和上传错误
- [ ] 浏览器测试覆盖管理员维护游戏、服务、封面和前台刷新
